# Easycheck-backend
Backend para easycheck creado con Nest

### 1. Instalar dependencias

```bash
npm install
```

### 2. Ejecutar servidor

```bash
npm run start:dev
```

## Scripts

```bash
npm run start
npm run start:dev
npm run build
npm run test
```

## Test
```bash

Integracion 
npm run test:integration

BDD
npm run test:bdd
```
